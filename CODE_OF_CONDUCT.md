# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the code and never about the
person. Harassment, insults and personal attacks of any kind are not welcome in issues, pull
requests, reviews or anywhere else the project lives.

## Reporting

If someone's behaviour makes you uncomfortable, contact a maintainer of this repository directly
and privately rather than replying in public. Every report is read, kept confidential, and
answered. Maintainers may remove comments, close threads, or block anyone who breaks this code,
as the Contributor Covenant's enforcement guidelines describe.
